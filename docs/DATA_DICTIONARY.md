# Dataset and artifact dictionary

All arrays are generated by the project notebooks; they are not real-world measurements. Read companion JSON for the saved summary metrics. The table below lists saved keys and shapes to aid discovery without making assumptions about array units.

| File | Purpose |
|---|---|
| [`phase3_observation_data.npz`](../data/phase3_observation_data.npz) | Three-basis observation matrix, reference source, sensor indices and noisy temperatures. |
| [`phase4_reconstruction_results.npz`](../data/phase4_reconstruction_results.npz) | Small-problem coefficient and spatial source estimates. |
| [`phase5_experiment_results.npz`](../data/phase5_experiment_results.npz) | 150-trial robustness sweeps for noise and sensor selection; penalty sweep. |
| [`phase6_large_inverse_data.npz`](../data/phase6_large_inverse_data.npz) | 25-basis response matrices for full and reduced sensor sets. |
| [`phase7_results.npz`](../data/phase7_results.npz) | Grid/model-mismatch experiment data and compact serialized summaries. |
| [`phase7_results_summary.json`](../data/phase7_results_summary.json) | Human-readable scenario rows and tuning sweep from Notebook 07. |
| [`phase8_results.npz`](../data/phase8_results.npz) | Adjoint experiment arrays plus an object-valued metrics member. |
| [`phase8_metrics.json`](../data/phase8_metrics.json) | Safe human-readable metrics from the adjoint experiment. |
| [`task9_validation_data.npz`](../data/task9_validation_data.npz) | Independent convergence, randomized sensor layouts, and timing arrays. |
| [`task9_validation_metrics.json`](../data/task9_validation_metrics.json) | Human-readable convergence, sensor layout and benchmark metrics. |

## Safe inspection examples

```python
import json
from pathlib import Path
import numpy as np

root = Path("data")
with np.load(root / "phase3_observation_data.npz", allow_pickle=False) as f:
    A = f["A"]
    print(A.shape)  # (48, 3)

metrics = json.loads((root / "phase8_metrics.json").read_text())
print(metrics["adjoint_vs_matrix_gradient_relative_error"])
```

**Security note:** `phase8_results.npz` contains an object array named `metrics`, which requires pickle-enabled loading. Avoid `allow_pickle=True` on untrusted archives; the equivalent summary is provided in `phase8_metrics.json`.
